## John Harrington

Independent consultant and solution architect in Hood River, Oregon. I build context
architecture for AI agents, and the practice that produces it.

### What I'm building

**[SWLL](https://swll.app)** — a local context layer for your files, browser history,
chats, and email. Indexed on your own machine, served to AI agents over MCP through
permission gates you set.

```bash
pipx install swll
```

**[Footprinter](https://github.com/harringjohn/footprinter-cli)** — SWLL's open-source
origin, MIT-licensed. Where the indexing model was worked out in the open.

### How I work

Two-week cycles aligned to the lunar phases: new moon to full is one leg, full to new is the
next, and the full cycle closes with a release. Every cycle ends in a written retrospective —
thirty-one of them since October 2025.

Most of this gets built alongside an AI agent, with the operating model treated as a
first-class artifact: the rules, the skills, the review gates, version-controlled the same way
the product is. The systems are the method, not scaffolding around it.
